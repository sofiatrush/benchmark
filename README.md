## Problem and motivation

У Telegram одна й та сама інформація швидко поширюється між каналами в ідентичному або зміненому формулюванні. Для автоматичного аналізу такого контенту важливо розрізняти:

- exact duplicate (однаковий текст)
- near-duplicate (той самий зміст із перефразуванням чи дрібними змінами)
- different (різні тексти)

Просте порівняння не завжди виявляє перефразування, а семантично схожі тексти можуть помилково визначатися як дублікати.

Мета проєкту - порівняти різні підходи до визначення схожості текстів на однакових даних і за єдиними критеріями. Оскільки повторюване поширення однакового або дуже схожого контенту між каналами може бути сигналом координованої інформаційної атаки, важливо зрозуміти, у яких випадках різні методи помиляються.

## Data

Використовуємо Aisberg Telegram News UA dataset (https://huggingface.co/datasets/aisbergpublicorganization/telegram-news-ua-dataset), доступний за ліцензією CC BY 4.0. Він налічує понад 200 тисяч деідентифікованих Telegram-постів із метаданими з 27-и українських новинних
каналів. Датасет містить тексти переважно українською, але також російською та англійською мовами. Пости згруповані в кластери, кожен з яких описує одну подію.
